# 邮件模板变量插值功能文档

## 功能概述

变量插值功能允许用户创建包含变量的邮件模板，并在发送邮件时用实际数据替换这些变量，实现个性化的批量邮件发送。

## 变量语法

在邮件模板中，变量使用双大括号语法表示：

```
{{变量名}}
```

还支持默认值设置，当变量不存在时将显示默认值：

```
{{变量名|默认值}}
```

例如：

```html
<p>尊敬的{{recipient_name|尊敬的用户}}：</p>
<p>感谢您对{{company_name|我们公司}}的支持。您的订单编号是 {{order_id}}。</p>
```

## 预定义变量

系统提供了一些预定义的变量类别和变量：

1. **收件人信息**
   - `{{recipient_name}}` - 收件人姓名
   - `{{recipient_email}}` - 收件人邮箱
   - `{{recipient_company}}` - 收件人公司
   - `{{recipient_title}}` - 收件人职位

2. **公司信息**
   - `{{company_name}}` - 公司名称
   - `{{company_address}}` - 公司地址
   - `{{company_phone}}` - 公司电话

3. **日期时间**
   - `{{current_date}}` - 当前日期
   - `{{current_time}}` - 当前时间

## 使用流程

### 1. 创建包含变量的模板

在模板编辑器中，可以使用"插入变量"按钮从预定义变量列表中选择变量，或者手动插入变量。

在编辑器中，变量会以特殊样式显示，以便与普通文本区分。

### 2. 导入收件人数据

批量发送前，需要导入收件人数据。系统支持以下数据导入方式：

- 上传CSV文件
- 上传Excel文件(.xlsx, .xls)

导入后，需要将数据列映射到模板变量。系统会尝试自动匹配，也可以手动调整映射。

### 3. 预览个性化邮件

导入数据并完成映射后，可以预览每个收件人的个性化邮件效果，以确保变量正确替换。

### 4. 批量发送

确认预览无误后，点击"批量发送"按钮将邮件发送给所有收件人。系统会自动为每个收件人生成个性化内容。

## 自定义变量

除了预定义变量外，用户还可以创建自定义变量：

1. 在"模板变量"选项卡中点击"添加变量"
2. 设置变量名称、显示名称和示例值
3. 点击"添加"按钮

变量名称规则：
- 只能包含字母、数字和下划线
- 不能与现有变量重名

## 技术实现

### 变量提取

系统使用正则表达式从模板中提取变量：

```typescript
const variableRegex = /\{\{([^|{}]+)(?:\|([^{}]*))?\}\}/g;
```

### 变量替换

变量替换过程如下：

1. 解析模板中的所有变量
2. 从导入数据中获取对应的值
3. 如果变量值不存在，则使用默认值
4. 将替换后的内容合并为最终邮件

### 数据导入和映射

数据导入过程：

1. 解析CSV/Excel文件获取表头和数据行
2. 自动匹配表头与模板变量
3. 用户验证和调整映射
4. 转换为系统内部数据格式

## 实现注意事项

1. **安全考虑**：变量值会在前端进行HTML转义，防止XSS攻击
2. **错误处理**：当导入数据有缺失或格式不正确时，系统会显示错误提示
3. **预览功能**：发送前提供预览，确保变量正确替换
4. **批量限制**：建议单次批量发送不超过1000个收件人

## 变量使用最佳实践

1. 使用有意义的变量名，便于理解和管理
2. 为重要变量提供默认值，避免空值
3. 预览每种类型的收件人数据，确保格式正确
4. 首次使用批量发送功能时，先发送少量测试邮件
5. 合理设计模板，即使所有变量都使用默认值也应保持合理外观

## 故障排除

1. **变量不替换**：检查变量名拼写，确保大小写一致
2. **导入失败**：检查CSV/Excel格式，确保有正确的表头行
3. **预览问题**：检查HTML模板格式，确保没有未闭合的标签
4. **发送失败**：检查网络连接和收件人邮箱格式
